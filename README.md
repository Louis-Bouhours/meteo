# 🌤️ Meteo

A clean and modern web application for checking real-time weather forecasts. This project is built with a fast, modern tech stack including Vite, Node.js, and Tailwind CSS, and it fetches data from the free and open-source [Open-Meteo API](https://open-meteo.com/).

!

## ✨ Features

* **City-Based Search:** Instantly retrieve current weather conditions for any city worldwide.
* **Detailed Forecasts:** Displays key weather data, including temperature, humidity, wind speed, and a weather description.
* **Responsive Design:** Fully responsive interface that adapts seamlessly to desktop, tablet, and mobile screens.
* **Fast Development:** Built with Vite for an incredibly fast and efficient development experience.

***

## 🛠️ Tech Stack

* **[Vite](https://vitejs.dev/)**: A next-generation frontend tooling solution.
* **[Node.js](https://nodejs.org/)**: A JavaScript runtime environment.
* **[Tailwind CSS](https://tailwindcss.com/)**: A utility-first CSS framework for rapid UI development.
* **[Open-Meteo API](https://open-meteo.com/)**: Provider of high-quality, open-source weather data.

***

## 🚀 Getting Started

Follow these instructions to set up and run the project on your local machine.

### Prerequisites

Ensure you have the following software installed:

* [Node.js](https://nodejs.org/en/) (v18.x or later is recommended)
* [npm](https://www.npmjs.com/) (included with Node.js) or [Yarn](https://yarnpkg.com/)

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/Louis-Bouhours/meteo.git](https://github.com/Louis-Bouhours/meteo.git)
    cd meteo
    ```

2.  **Install dependencies**
    Choose your preferred package manager:
    ```bash
    # Using npm
    npm install

    # Or using Yarn
    yarn install
    ```

3.  **API Configuration**
    No API key is required to use the Open-Meteo API for non-commercial projects. You can proceed directly to running the application.
